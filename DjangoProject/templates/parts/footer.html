Dúvidas Frequentes (FAQ)

Como o SIMADU emite os alertas de alagamento?

O sistema monitora dados meteorológicos em tempo real (INMET/OpenWeather) e sensores de nível d'água instalados em pontos críticos de Corumbá, disparando avisos automáticos quando os limites de segurança são atingidos.

Quem pode se cadastrar para receber os alertas?

Toda a população de Corumbá pode se cadastrar gratuitamente para receber notificações preventivas diretamente no navegador, e-mail ou por SMS.

Os meus dados pessoais estão seguros?

Sim. O tratamento de dados pessoais segue rigorosamente as diretrizes da Lei Geral de Proteção de Dados (LGPD).
